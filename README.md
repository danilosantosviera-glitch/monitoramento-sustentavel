🌱 Monitoramento Digital de Água e Energia

Tecnologia para a Economia Doméstica Sustentável

Este projeto é uma Aplicação Web Interativa (Single-File App) desenvolvida como parte de uma Atividade de Extensão Universitària. O objetivo principal é proporcionar uma ferramenta simples, acessível e completa para famílias acompanharem o consumo e os custos de água ($m^3$) e energia elétrica ($kWh$), promovendo a conscientização socioambiental e o planejamento financeiro doméstico.

📌 Funcionalidades Principais

💧⚡ Registros Independente de Consumo: Cadastre e atualize faturas de água e energia separadamente ou juntas.

📊 Dashboards e Gráficos de Evolução: Visualização separada do consumo em volume ($m^3$e$kWh$) e dos valores pagos em reais ($\text{R}$).

⚖️ Comparador Diário Ajustado: Divisão automática por número de dias do ciclo para comparar faturas com períodos diferentes sem distorções.

🎯 Metas e Alertas Inteligentes: Definição de metas mensais e avisos automáticos de aumentos atípicos de consumo diário.

🔮 Previsão de Próxima Conta & Simulador: Estimativa com leituras intermediárias e simulação de economia em tempo real.

🤝 Diário de Ações Sustentáveis: Anotação de mudanças de hábitos familiares (ex: troca para lâmpadas LED, conserto de vazamentos).

🎓 Painel de Extensão Acadêmica: Geração automática de relatórios resumidos e indicadores ambientais (Litros poupados e $\text{kg de CO}_2$ evitados) prontos para impressão/PDF.

💾 Persistência de Dados Local: Todos os dados ficam salvos com segurança no próprio dispositivo do usuário (localStorage).

🛠️ Tecnologias Utilizadas

O projeto foi inteiramente construído em um único arquivo integrado contendo HTML5, CSS (Tailwind) e JavaScript, facilitando a implantação imediata em servidores de hospedagem estática como o GitHub Pages:

HTML5: Estruturação semântica e acessível.

Tailwind CSS: Estilização moderna, responsiva (adaptada para smartphones, tablets e desktop) e acessível.

JavaScript (ES6+): Lógica de negócios, cálculos de tarifas, simuladores e persistência de dados.

Chart.js: Renderização de gráficos interativos de evolução.

FontAwesome: Ícones representativos para facilitar a navegação.

📱 Responsividade e Acessibilidade

O aplicativo foi projetado sob a filosofia Mobile-First, garantindo:

Adaptação a qualquer tela: Layouts em grade flexíveis que se ajustam desde telas pequenas de celular até monitores de alta resolução.

Guia Visual de Leitura: Modal de ajuda com exemplos claros para orientar pessoas com pouca familiaridade com tecnologia a encontrar os dados na conta de luz ou água.
